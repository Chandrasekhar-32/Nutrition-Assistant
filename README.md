# 🥗 Nutrition Assistant App

A modern full-stack Nutrition Tracking and Analysis Web Application built with Next.js.  
It helps users track meals, monitor nutrition intake, and maintain a healthy lifestyle with a clean dashboard experience.

## 📌 Features

- 🔐 User authentication (Better Auth)
- 🍽️ Meal & food tracking system
- 📊 Nutrition analytics dashboard
- 🧠 Smart nutrition insights (AI-ready structure)
- 📅 Daily health progress tracking
- ⚡ Fast performance with Next.js App Router
- 📱 Fully responsive UI (mobile + desktop)

## 🛠️ Tech Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- React Query
- Better Auth
- Yarn 4 (Package Manager)
- Turbopack (Dev Server)

## ⚙️ Installation & Setup

### 1️⃣ Clone repository
git clone https://github.com/Chandrasekhar-32/Nutrition-Assistant.git
cd Nutrition-Assistant

---

### 2️⃣ Install dependencies
yarn install

---

### 3️⃣ Run development server
yarn dev

App runs at:
http://localhost:4000

---

### 4️⃣ Build for production
yarn build

---

## 🌐 Deployment (Vercel)

1. Go to https://vercel.com
2. Import GitHub repository
3. Set root directory to:
   apps/web
4. Click Deploy 🚀
